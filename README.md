# Binance Signal Scanner

یک صفحهٔ استاتیک (فقط HTML/CSS/JS) — سرور و بک‌اند ندارد. داده را مستقیماً مرورگرِ هر کاربر از Binance می‌گیرد.

## بالا آوردن روی GitHub Pages
1. در GitHub یک repository **Public** بسازید (مثلاً `scanner`).
2. دکمهٔ **Add file → Upload files** را بزنید و این‌ها را آپلود کنید: `index.html`، `app.js`، `styles.css`، `.nojekyll` (و همین README).
   فایل‌ها باید مستقیم در ریشهٔ repo باشند، نه داخل یک پوشه.
3. **Settings → Pages → Build and deployment**: گزینهٔ *Deploy from a branch*، شاخهٔ `main`، پوشهٔ `/ (root)` → Save.
4. بعد از ۱ تا ۲ دقیقه آدرس سایت می‌شود: `https://USERNAME.github.io/REPO/`
5. برای به‌روزرسانی فقط فایل‌های جدید را دوباره آپلود (Replace) کنید.

## اتصال از ایران
- خودِ Binance از IP ایران و از IP آمریکا ممکن است جواب ندهد. با VPN (کشور غیر از آمریکا، مثلاً آلمان/ترکیه/امارات) هم صفحه و هم Binance باز می‌شوند.
- اگر `github.io` روی اینترنت دوستانتان باز نشد، یک راه بدون هیچ هاستی: پوشهٔ پروژه را zip کنید و در تلگرام بفرستید؛ دوستتان آن را باز کند و روی `index.html` دوبار کلیک کند. (فقط به دسترسی Binance، یعنی VPN، نیاز دارد.)
- صفحه هیچ فونت یا اسکریپت خارجی ندارد، پس تنها وابستگی‌اش خود Binance است.
